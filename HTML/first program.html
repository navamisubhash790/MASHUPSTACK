Html Introduction

HTML was created by Tim Bernes Lee. It is maintained by W3C ( World Wide Web Consortium ). The older versions of HTML include HTML2, HTML3 and HTML4. The current version of HTML is HTML 5 HTML is written in a plain text file using Notepad. The file has .html as its extension. The HTML file includes various HTML tags used to represent various elements such as tables, images, videos etc and we will learn more about it in the coming chapters.

You can use Notepad to edit any normal text. However, notepad has very limited features. When you start creating larger code, it becomes difficult and extremely time consumig to code in Notepad. There are more powerful editors available. Some of them are free while some of them are paid. However, all of them have more features than Notepad.
